# DámeNic

Simulátor rozvozu jídla: vybereš si ve fiktivní restauraci, objednáš nanečisto za 0 Kč, sleduješ smyšleného kurýra a na konci dostaneš
skutečný recept, odhad nákladů a nákupní seznam. Web: https://damenic.cz

Statický web v Astro 7 + Preact ostrovy, hostovaný na Cloudflare Workers Static Assets. Bez serveru, databáze, účtů a analytiky.

- Přidání restaurace, jídla, receptu nebo partnera: [CONTENT_GUIDE.md](CONTENT_GUIDE.md)
